# VPN Setup Guide

To work remotely, install the Acme VPN client from the IT portal. Sign in with your company SSO account. After the password step, the VPN asks for a second factor: approve the login in your authenticator app.

The VPN gateway address is vpn.acme-example.com. If the client shows error 809, a firewall or home router is blocking the connection. Allow UDP ports 500 and 4500, or try a different network such as a mobile hotspot.

If the connection drops often, restart the client and check that your system clock is correct. For any other remote access problem, post in the #it-help channel with your error message and operating system.
